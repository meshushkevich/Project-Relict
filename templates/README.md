# Шаблоны документов

- [Существо](creature.md).
- [Аномалия](anomaly.md).
- [Инцидент](incident.md).

Скопируй подходящий шаблон в тематическую папку, замени название и подсказки. Новый документ остаётся `draft`. Поля `id`, `date` и `location` обязательны только для инцидентов. `TBD` означает, что значение ещё не определено; неизвестные свойства не заполняются догадками.

Разделы можно сокращать, если данных нет. Подсказки в HTML-комментариях предназначены автору: перед готовым читательским текстом их нужно убрать. Скрытые объяснения размещаются в авторской базе, а не в комментариях читательского файла.
