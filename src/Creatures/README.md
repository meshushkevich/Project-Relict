# Существа

Карточки отдельных живых форм. Каждая карточка — документ внутри мира: доступные составителю наблюдения, поведение и известные случаи появления. Скрытая природа и планы развития хранятся отдельно в авторской базе.

Карточек пока нет. Существа не выводятся автоматически из нераскрытых происшествий.

Используй [шаблон существа](../../templates/creature.md); черновик остаётся в этой папке с `status: draft`.
