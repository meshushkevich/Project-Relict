# Персонажи

Утверждённые автором досье участников инцидентов. Все 15 досье имеют `status: canon` и пока не включены в оглавление книги. Статус досье не меняет статус исходного инцидента.

На этом этапе в досье собраны сведения из существующих дел: биография до происшествия, действия человека, показания и последнее известное положение. Там, где источников нет, оставлены пробелы. Не добавлены новые места работы, родственники, диагнозы, встречи или события после блокады.

## Дальнейшая разработка

Для расширения биографий нужны отдельные авторские решения. Новые сведения сначала оформляются как предложения с явным отличием от фактов исходного дела. После утверждения обновляются соответствующее досье и связанные материалы.

Не отождествляй Миронову с пассажиркой автобуса, кисть в стене — с останками Воронина, а фамилию на записи из дела 001 — с конкретным членом семьи Беляевых. Эти связи не установлены.

События после блокады не описаны. Сведения о ГБС, доступные составителю позднего отчёта, не означают, что ими располагал свидетель.
