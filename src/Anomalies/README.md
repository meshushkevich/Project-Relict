# Аномалии

Карточки необычных объектов, мест и процессов. Каждая карточка — документ внутри мира: наблюдаемые проявления, известные условия и связанные события. Разделение с существами служит организации материалов и не задаёт научную классификацию вселенной.

Карточек пока нет. Отдельное странное происшествие может оставаться только инцидентом, без установленного объяснения.

Используй [шаблон аномалии](../../templates/anomaly.md); черновик остаётся в этой папке с `status: draft`.
